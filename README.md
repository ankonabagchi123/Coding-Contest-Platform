# 🏆 CodeArena — Online Coding Contest Platform

A full-stack MERN application for hosting coding contests with real-time code execution and ICPC-style leaderboards.

## 🎯 Features

- 🔐 JWT authentication with role-based access
- 📝 Problem management with hidden + sample test cases
- 🏁 Contests with scheduled start/end + registration
- ⚡ Real-time code execution (Piston API — free, no key)
- 🏆 ICPC-style leaderboard (score + penalty ranking)
- 💻 Monaco editor (VS Code engine) with 9 languages
- 📊 Submission history with detailed verdicts

## 🛠 Tech Stack

**Backend:** Node.js, Express, MongoDB Atlas, Mongoose, JWT, Piston API
**Frontend:** React 19, Vite, Redux Toolkit, React Router, TailwindCSS, Monaco Editor
